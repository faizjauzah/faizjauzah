## 🚀 Featured projects

### 🛒 Semi-supervised Retail Product Detection (undergraduate thesis)

Labeling bounding boxes is expensive. I used **YOLOv12-Nano with Noisy Student Training** to detect infant formula products on retail shelves with far fewer labels.

- With only **50% of the data labeled**, the model reaches **~97.2% of fully supervised performance**, which cuts annotation cost in half.
- Tested on two datasets (47 and 49 classes) across ten labeling-ratio scenarios (10% to 100%).

`Python` `YOLOv12` `Ultralytics` `Streamlit`

[**▶ Live demo**](https://demo-object-detection.streamlit.app) · [**Code**](https://github.com/faizjauzah/demo-object-detection)

### 🏎️ F1 Regulations Copilot (RAG)

Ask a question about the FIA rulebooks and get an answer **with the exact source paragraphs it relied on**, so you can check it instead of trusting it.

- Clause-based chunking over 6,000+ chunks from the FIA regulation PDFs (Sections A to F).
- FastAPI backend, ChromaDB vector store, fully containerized with Docker.
- Runs on a hosted LLM or a local model, and includes an evaluation script.

`Python` `FastAPI` `ChromaDB` `Docker`

 [**Code**](https://github.com/faizjauzah/f1-rulebook-rag)
